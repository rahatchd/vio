# vio

VIO - VI wOrsened:
a modal text editor with a subset of the features of VI

## requirements

- [ncurses](https://invisible-island.net/ncurses/)
- gcc
- make

## build

```sh
make
```

## run

```sh
./vio <filename>
```

## features

- [x] load file
- [x] render file
- [x] hjkl motions
- [x] remember column position
- [x] status bar
- [ ] scrolling
- [x] insert mode
- [ ] write and exit commands (ie ':')
- [ ] save file
- [ ] word vim motions
- [ ] number modifiers
- [ ] show line numbers
